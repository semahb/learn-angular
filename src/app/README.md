# Learn Angular Project

This project is a learning exercise to understand and implement basic Angular components, services, and features.

## Directory Structure
- `app`
  - `git`
    - `learn-angular`
      - `src`
        - `app`
          - `components`
            - `{name}.component.ts`
          - `services`
            - `{service-name}.service.ts`
          - `app.module.ts`
          - `main.ts`

## Setup Instructions
1. Install Angular CLI globally if not already installed:
   ```bash
   npm install -g @angular/cli
   ```
2. Navigate to the project directory:
   ```bash
   cd /app/git/learn-angular
   ```
3. Initialize a new Angular project:
   ```bash
   ng new learn-angular --strict
   ```
4. Navigate into the project:
   ```bash
   cd learn-angular
   ```
